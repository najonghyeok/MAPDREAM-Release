# MAPDREAM 설치 파일

설치 파일(zip)만 올리는 곳입니다. 오른쪽 **Releases**에서 최신 버전을 받으세요.

| 프로그램 | 대상 | 받기 |
|---|---|---|
| **MAPDREAM** | AutoCAD 2021 ~ 2027 | [최신 버전](https://github.com/najonghyeok/MAPDREAM-Release/releases?q=mapdream-v&expanded=true) |
| **MAPDREAM BIM** | Revit · Navisworks | [최신 버전](https://github.com/najonghyeok/MAPDREAM-Release/releases?q=bim-v&expanded=true) |

## MAPDREAM (AutoCAD) 설치

1. AutoCAD를 모두 닫습니다.
2. zip을 `C:` 드라이브 바로 아래에 풉니다. (예전 MAPDREAM 폴더가 있으면 덮어쓰기)
3. `MAPDREAM` 폴더의 `설치.bat`을 실행합니다.
4. AutoCAD를 켜고 `MD_KEYS` → **[MAPDREAM 단축키 넣기]** 로 단축키를 넣습니다.

- AutoCAD 2027을 처음 설치했다면 한 번 켰다 끈 뒤에 설치하세요.
- 지우려면 `제거.bat`을 실행합니다.
- 명령 설명은 AutoCAD에서 `MD_HELP` 를 입력하세요.

## MAPDREAM BIM (Revit · Navisworks) 설치

1. Revit · Navisworks를 모두 닫습니다.
2. zip을 아무 곳에 풉니다.
3. `MAPDREAM_BIM` 폴더의 `설치.bat`을 실행합니다. (설치된 Revit 2024 / 2026, Navisworks Manage 2026을 찾아서 넣습니다)
4. Revit / Navisworks를 켜면 **MAPDREAM BIM** 탭에서 사용할 수 있습니다.

- 업데이트할 때도 새 zip을 받아 `설치.bat`을 다시 실행하면 됩니다.
- 예전 이름(THUGSO)으로 설치돼 있으면 `설치.bat`이 자동으로 지웁니다.
